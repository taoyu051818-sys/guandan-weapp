## 启动

在 Cocos 项目目录执行：

```sh
node tools/lobby-layout-lab/server.mjs
```

打开 <http://localhost:18742/>。可用 `LOBBY_LAB_PORT` 指定其他端口。仅监听 `127.0.0.1`，手机无法直接通过 localhost 访问。

不安装新依赖；使用项目已有 TypeScript 转译器。修改源码后刷新页面即可，不需要启动 Cocos 或重新构建微信包。

## 共用与模拟的边界

- `assets/scripts/ui/LobbyLayoutPolicy.ts` 仅保留正式定稿几何；`baseline-layout.ts` 保存旧几何，供本工具的原版／候选 01 使用，不进入游戏包。
- 共用 `SafeAreaLayout.ts` 账户横向布局算法、`TableLayoutOverlapAudit.ts` 重叠测量。
- 使用真实本地原图；不重新生成或替换美术素材。
- 账户示例、点击反馈、恢复状态是模拟，不调用账号、商城、房间或匹配接口。
- Canvas 字体、描边、九宫格/图形渲染与 Cocos 不完全相同；它适用于位置、尺寸、主次和留白的迭代，不是最终像素级渲染承诺。
- 头像框、标签等内部叠层不作为布局冲突；区域重叠只告警，不强制移动。透明贴图按矩形边界计算，不是 alpha 像素遮挡检测。

## 操作与定稿

1. 原版／候选切换比较；调滑块或直接输入数值。
2. 切换普通、恢复、长昵称状态，检查安全区预设。
3. 显示辅助线，查看重叠宽高、面积及占两区域的各自比例。
4. 保存到本机（版本化 localStorage，仅当前浏览器）；导出 JSON 与 874 × 402 PNG。
5. 用户确认候选后，将选中的参数接入 Cocos，并在同尺寸截图、不同长宽比、微信真机中验收字体、触控与安全区。

候选 02 定稿已接入 Cocos 源码；历史构建目录未覆盖。服务仅提供显式允许的文件与素材，其他路径返回 404；CSP 禁止连接游戏服务。
