# 运营后台 v1：交付与验收（2026-09-26）

## 交付边界

已完成独立网页后台、管理员认证、公告、反馈、服务开关、审计及 Cocos 消息/反馈入口。正式地址已由用户确认：`https://api.yutechhn.cn/admin/`。

**本轮是代码、本地联调与构建完成，不代表已部署服务器、上传微信体验版或通过微信真机验收。** 正式管理员密码与 TOTP 绑定由用户私密完成；未创建默认生产账号，未改线上玩家数据。

| 模块 | 职责与边界 |
| --- | --- |
| `work/guandan-admin` | 无外部运行依赖的管理网页；按角色导航、真实 API、纯文本公告与回复、失败保留输入、版本冲突确认 |
| `server/platform/admin-*` | 独立管理员凭据、密码校验、TOTP、Cookie 会话、离线账号初始化、静态资源白名单 |
| `server/platform/operations-*` | 公告有效期、玩家隔离、反馈幂等与限流、功能状态、并发版本、变更审计 |
| Cocos `OperationsPage*` | 玩家消息/反馈页面状态、视图和生命周期；不包含管理员认证或后台网页 |
| Cocos `operationsGateway` | 复用现有玩家认证客户端；校验响应字段，不接受客户端伪造用户 ID |

公告支持草稿、发布、下线、归档、有效时间；没有不可恢复删除。反馈支持分类、回复和处理状态。会员只能关闭/维护，不伪造已实现的权益或支付能力。任务、会员权益、商城订单不是本轮新增功能。

数据使用现有平台存储的独立 `operations` 分区，共享同一事务写入者；没有另起进程同时改 JSON。管理员凭据另存私有文件。反馈审计仅保留状态摘要和本次新回复，不复制全部历史；审计按 UTF-8 字节计算，上限 32 MiB，满额时拒绝并回滚业务写入，不静默删除历史。

## 本地独立验收环境

在仓库根目录运行 `node scripts/operations-preview.mjs`，仅监听 `127.0.0.1:18743`，全部业务数据在内存中。随机测试凭据写入系统临时目录的私有文件（控制台仅输出路径）；退出时清理该目录。此账号不是生产账号。

先构建 Cocos Web，然后在 `work/guandan-cocos` 运行 `NODE_ENV=development node scripts/operations-game-preview.mjs`。游戏预览在 `http://127.0.0.1:18744/`，仅将玩家 API 转给本机 18743，拒绝管理 API；正式构建文件和正式网络配置不会被这个预览脚本改写。

后台地址：`http://127.0.0.1:18743/admin/`。这两个测试进程均禁止生产模式，关闭后不保留测试业务记录。不要把测试凭据、测试登录文件或调试入口带到线上。

本机预览现为账号密码登录，无需安装验证器。`operations-preview.mjs` 显式启用 `ADMIN_ALLOW_PASSWORD_ONLY_LOCALHOST=true`；服务端要求同时启用非生产 loopback 模式，生产或对外绑定直接拒绝启动。登录页根据服务端 `login-options` 隐藏验证码并取消必填，加载失败可重试；密码哈希、限流、Origin、CSRF 和角色校验保持。可使用第三个命令行参数指定已有私有凭据文件，退出不删除该外部文件，不把账号密码写入仓库。正式环境要求不变。

## 用户验收流程

| 顺序 | 操作 | 通过标准 | 待用户验收 |
| --- | --- | --- | --- |
| 1 | 绑定管理员 TOTP；错误密码/正确密码登录 | 错误拒绝；正确登录按角色进入，不显示其他角色权限 | 正式环境 |
| 2 | 新建公告但不发布；游戏打开消息 | 草稿不出现 | 微信真机 |
| 3 | 预览后发布，再进入消息查看 | 正文完整、换行正确、已读保存；重新进入不重复计未读 | 微信真机 |
| 4 | 设置未来开始/到期时间、下线/恢复公告 | 有效期由服务端控制，过期/下线不可继续读取 | 正式联调 |
| 5 | 游戏输入反馈，切后台、返回再提交 | 原生键盘可输入；不遮挡提交；返回不串页；重复点击不重复提交 | 微信真机 |
| 6 | 后台回复、标记已处理；玩家查看 | 仅提交者看到回复，消息和“我的反馈”都能读取 | 微信真机 |
| 7 | 将反馈改为维护，再尝试提交 | 显示后台文案；直接调用提交 API 也拒绝；恢复开放可用 | 正式联调 |
| 8 | 两个管理员同时修改同一条记录 | 后保存者收到版本冲突，输入保留，不覆盖对方修改 | 正式联调 |
| 9 | 检查审计与退出登录 | 每次管理写入有操作者、前后内容；退出后旧会话不可写 | 正式联调 |
| 10 | 弱网、断网、重进页面；检查大厅和牌局 | 有加载/错误/重试状态，无假成功；原有大厅/牌局不受影响 | 微信真机 |

更细的玩家端验收见 `work/guandan-cocos/docs/operations-player-acceptance.md`；部署步骤见 `docs/operations-deployment.md`；字段契约见 `docs/operations-v1-contract.md`。
