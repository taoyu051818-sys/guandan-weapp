# 统一矩形框体（2026-09-09）

## 开发约定

唯一几何来源：`assets/scripts/ui/UiFrameStyle.ts`。不增加第三方 UI 库。

| 语义 | 圆角（节点本地单位） | 用途 |
| --- | ---: | --- |
| panel | 8 | 弹窗、个人中心、结算面板、信息区域 |
| control | 6 | 普通/按下/禁用按钮、输入框、快捷语、花色工具条 |
| tag | 3 | 牌组名称、状态标签、紧凑信息条 |
| progress | 2 | 加载进度条 |
| square | 0 | 全屏遮罩、背景色块 |

半径不超过短边的 20%，小标签和窄进度不会重新变成胶囊。无效或零尺寸不生成路径。主题常量冻结；页面不能传入任意 radius 覆盖主题。

- `RuntimeUiFactory.panel/button` 用 `frame` 选择语义，手动缩放的大厅用 `frameScale`。
- 直接使用 Cocos Graphics 时调用 `drawUiFrame`；调用方负责颜色、填充、描边，不改变位置、尺寸、点击区域或动画。
- 微信资料授权按钮使用 `uiFrameRadius`，同样走统一规则；它不同于系统右上方原生胶囊。
- 布局模拟器候选 02 使用相同模块，历史基准不改。
- 扑克牌轮廓、锁标记、商品插图、头像边框、圆形倒计时和花色图标不属于胶囊承载框，保留原画法。
- 微信右上角“更多/关闭”是系统 UI，保留原生形状及避让逻辑。

## 覆盖范围

大厅、好友房设置/等待、资料编辑/个人中心、商城预览、结算/对局回看、牌桌信息/操作按钮/记牌器/花色栏、玩家状态/聊天，以及开屏加载/重试。没有增加面板、放大布局、调整文字或恢复退役功能。

## 回归

`tests/ui-frame-style-regression.cjs` 已加入默认测试：

1. 所有语义的长/短/方/窄框体几何、缩放、零尺寸。
2. 实际 RuntimeUiFactory 的普通、按下、取消、禁用、遮罩和聊天标签。
3. 保持原有宽高及点击区域。
4. 扫描所有运行时源码，禁止新建局部圆角画法；仅按数量列出原有卡牌/插画例外，微信按钮禁止独立 borderRadius。
5. 既有字号、HUD、牌组标记和动效生命周期回归同步验证。
