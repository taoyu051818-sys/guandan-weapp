# 好友房直接入桌（2026-09-09）

> 后续需求更新：用户已重新要求“六位房号弹窗加入”，见 `friend-room-number-and-variants-20260909.md`。下文“只保留创建”是上一轮交付记录，长口令页仍保持退役。

## 玩家流程

- 配置规则 → 点击创建房间 → 立即显示牌桌及创建进度 → 服务端入房确认 → 显示座位、邀请、准备。
- 邀请好友只在牌桌内发送微信邀请卡片；接收者点击卡片自动入桌，不输入或粘贴口令。
- 创建失败返回原规则配置，保留草稿；邀请失败返回大厅并说明原因。
- 请求中可以取消，迟到的创建结果不得打开牌桌，并须释放已申请席位。
