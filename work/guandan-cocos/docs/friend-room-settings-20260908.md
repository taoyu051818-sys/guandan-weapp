## 仍需说明或决策，尚未开放

1. **复式**：同牌比较的参赛范围、是否跨桌、复用牌号、固定/不固定级牌序列、计分比较和并列规则。现有独立定局不能冒充复式。
2. **转蛋**：随机抽牌如何确定搭档、轮换周期、顺时针究竟轮换哪些座位、3分/6分的逐名次分配与累计。还需个人成绩而不是当前固定队伍累计分。
3. **不洗牌**：首局生成方式、之后的收牌顺序、切牌/洗牌范围、按张还是按组发牌。不能简单“不打乱全新有序牌堆”，也不能偷偷改成提高炸弹概率。
4. **四炸起加倍**：每个合格炸弹乘2还是按长度递增、同花顺/天王炸如何算、计分或升级是否受影响、封顶及范围。未改钱包与任何奖励。
5. **防作弊**：若截图指同IP/GPS或限制查看队友手牌，需要另行明确机制、误伤处理和隐私授权；当前只声明现有服务端牌权/合法出牌校验。
