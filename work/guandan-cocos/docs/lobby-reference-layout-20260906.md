# 大厅参考布局改版 · 2026-09-06

本轮只改大厅。依据用户提供的棋牌大厅截图，采用账户区、主玩法区、辅助玩法区、底部功能区，而不是三条等大的右侧横栏。没有修改游戏桌、规则、匹配协议、选牌反馈或旧特效启停。

## 布局与入口

874 × 402 为大厅独立设计坐标，等比放入 ScreenAdapter 安全区；不改全游戏坐标系。

|区域|设计稿矩形 x / y / w / h（px）|行为|
|---|---|---|
|经典掼蛋|128 / 76 / 338 / 252|进入现有经典场次选择|
|好友房|480 / 76 / 374 / 146|进入现有创建/加入流程|
|赛事|480 / 234 / 374 / 94|只读筹备介绍|
|主操作|554 / 346 / 300 / 48|经典初级场；有恢复记录时改为返回对局|

顶部只显示头像、昵称/ID、积分。胜率、场次、综合分不再挤占大厅；个人资料入口保留。右上不放操作控件，留给微信胶囊。

底部固定商城、玩法说明、更多；不放未接入的活动按钮或虚假红点。更多使用独立大厅设置弹窗，只含特效质量和个人资料，不连接旧的实验/人机测试菜单。遮罩与面板阻断穿透点击，账户异步刷新及重排后保留该弹窗。

## 视觉与动效

保留现有陵水海岸背景及已生成的插画；页面级蓝色遮罩降低背景干扰，不改加载和牌桌背景。经典入口采用独立标题底板，好友房次之，筹备赛事降低面积与亮度。

UI/UX 技能用于约束层级、稳定点击区域、有限动效和精简模式。面板仅短距离错峰入场；按压只缩放视觉子节点，回调不等待动画。页面数据刷新和尺寸重排不重复入场。浏览器减少动态效果偏好，以及游戏精简/关闭档均关闭入场动画；不创建循环粒子或背景计时器。沿用 PageRouter 对节点 Tween 的递归清理。

这不是骨骼动画交付。当前插画尚未拆分和绑定，角色样例留待造型确认后制作，不用整图漂浮冒充骨骼动作。

## 验收

新增 `tests/lobby-landing-regression.cjs`：验证四个主要入口独立边界、面积层级、四种横屏安全尺寸、取消按压不跳页、按压不移动点击框、恢复文案、精简模式及刷新不重播。原测试仅更新被新布局替代的旧断言，保留平台和好友房流程保护。

需真人在 874×402 及微信真机检查：经典选场、好友房、赛事、商城/详情返回、规则翻页、更多切换特效和返回，以及有未结束牌局时的恢复。不要把自动化边界测试当作美术效果或真机触控已经通过。
