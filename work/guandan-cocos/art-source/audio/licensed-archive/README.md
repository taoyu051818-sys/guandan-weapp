# Licensed audio source archive

These project-authorized MP3 files are intentionally outside Cocos `assets/`.
They remain available for provenance audits and reproducible imports, but have
no runtime route and must not receive Cocos `.meta` files.

- `straight_flush.mp3` is superseded by the sole canonical
  `niuma/straight_flush` announcement.
- `pair_a_phrase.mp3` has an unconfirmed product meaning and is not eligible
  for automatic playback.

Source URLs, byte counts, and SHA-256 hashes are recorded in
`third_party/licenses/gameabc2-audio/manifest.json`.
