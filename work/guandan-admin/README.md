# 掼蛋运营工作台

独立原生 HTML/CSS/ES Modules 管理端，无构建依赖、无第三方 CDN、无生产演示数据。由现有平台服务同源提供 `/admin/`，不得直接使用 `file://` 或另起跨域静态服务连接生产接口。

## 启动与验证

管理账户、TOTP、Cookie、Origin 和平台服务启动配置由服务端维护，见服务端运营文档。启动配置完成后访问同源 `/admin/`。本目录不存储任何账号密码或 TOTP 秘钥。

本机独立预览使用账号密码即可登录。页面通过 `/api/v1/admin/login-options` 读取是否需要验证码，不按浏览器地址猜测，也不由前端关闭验证。配置读取失败时禁用提交并提供重试。正式环境仍要求 TOTP；只有显式非生产 loopback 配置允许测试时免验证码。

```sh
cd work/guandan-admin
npm run verify
```

无需 `npm install` 或编译。`verify` 检查所有运行时模块语法和 import、纯文本 DOM 渲染、无本地凭据持久化、CSP 兼容 HTML，并运行 Node 内置测试。静态生产入口仅 `index.html`、`styles.css`、`src/*.js`；测试、脚本与此 README 不应公开。

## 工作流

- 管理员：公告、反馈、功能开关、只读审计；运营：前三项；客服：仅反馈。隐藏导航只是辅助，服务端必须继续独立校验每个权限。
- 公告：新建草稿、编辑、纯文本预览、发布、下线、归档、恢复草稿、时间窗口；所有更新携带版本。契约无 DELETE，归档是可恢复的移除流程。
- 反馈：按处理状态筛选、分页、完整正文/回复、回复与处理状态更新；冲突可载入最新版本并保留回复草稿。
- 功能开关：修改前确认，记录版本；会员服务不可开放，无支付、充值、订单相关实现。
- 会话：仅使用同源 HttpOnly Cookie；CSRF 仅保存在内存。刷新通过 session 接口恢复；会话过期不清空正在输入的表单，可在原页面重新验证。切换到不同账户后重载工作台，避免跨账户保留旧数据。
- 未保存内容：切换记录/页面会确认，刷新/关闭由浏览器离开提示保护。不持久化管理员草稿。网络失败不会自动重试写请求，请核对服务器状态后再提交。

## 手动验收

1. 在 375、768、1440 像素宽度和横屏检查登录、列表、编辑器、审计长文本；放大 200% 后无页面水平滚动。
2. 仅键盘完成登录、导航、预览、确认与取消；Escape 关闭原生 dialog，焦点回到触发控件。取消按钮默认获得确认弹窗焦点。
3. 密码管理器与验证码粘贴可用；表单错误保留输入；所有输入有可见标签；按钮等待时禁用；结果通过状态区域宣告。
4. 使用两个会话修改同一记录，确认 409 不覆盖表单，明确选择最新版本后才重载。
5. 管理员/运营/客服逐一验证路由；无权限 hash 导航回到允许页面；服务端拒绝越权直接 API 调用。
6. 验证登录过期、失败响应、网络断开、空列表、分页、公告时间窗口与成员服务不可开放。
7. 使用包含 `<script>` 与长 URL 的公告/反馈验证纯文本呈现；审计 JSON 为 text nodes，无 HTML 插入。

界面使用系统中文字体、深蓝侧栏与浅色内容面板，4–8 像素小圆角，无图片和动画依赖。遵循 UI/UX 技能中的可见焦点、明确错误恢复、44 像素交互目标与减少动态效果约束。
