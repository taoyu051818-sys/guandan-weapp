## 实现边界

`FrontPageController` 在 matching 路由进出时复用现有空牌桌等待生命周期（`setFriendRoomWaitingVisible`），背景提前变为牌桌，旧手牌、座位与 HUD 不激活。只有服务端有效房间凭证和牌局快照才能进入真实对局。

`MatchmakingPageView` 只负责表现；`MatchmakingPageDomain` 的排队、轮询、7 秒机器人补位规则、取消竞态和房间凭证校验不回退。路由销毁原有递归 Tween 清理会同时清理三张洗牌节点。

不复原历史版本的旧取消实现，不虚构玩家头像、人数或手牌，不增加电子音、素材、骨骼依赖。大厅及本轮之前的个人资料修改保留。
