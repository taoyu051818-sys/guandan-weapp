# 牌桌记牌器与牌面精修 — 2026-09-08

## 本轮修改

- 记牌器：取消自动布局坐标的持久缓存，只保存实际拖动位置。首次显示即使用展开后的完整高度做安全区/微信胶囊避让；展开折叠保持同一横坐标、同一顶部边缘。保留经过确认的横向锚点，避免紧凑 HUD 缩放时向右漂移。
- 双行本局信息：底板宽度由 272 改为 240 Cocos 单位，圆角由半高 42 改为 8；文字区域两侧各留 8。保持返回按钮下面的位置。
- 选牌：删除普通牌及向下叠牌露出条上的金色描边，保留已有中性明暗反馈。未改变触摸坐标、滑选、牌序、命中区域或锁牌逻辑。
- 级牌：删除整张牌的黄色滤镜和金色描边，改为右上角绿色三角、白色“级”字。重绑普通牌时隐藏角标，避免复用残留。
