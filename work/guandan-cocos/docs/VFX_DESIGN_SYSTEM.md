# 海岛夜局 VFX 设计系统

## 目标

牌桌特效首先服务于出牌识别和操作节奏，其次才是炫技。所有实战效果统一使用同一套色彩、层级、时间语法、排版和移动端预算；EffectLab 可以预览完整、精简、关闭三档，规则层不直接引用贴图。

## 视觉主题

主题名为“海岛夜局”。墨色暗场承接牌桌环境，玉青用于系统反馈，冰蓝用于技巧牌型，暖金用于荣誉，金焰用于炸弹，灰银用于中性和失败。不同语义保留明确色相，不将界面做成单一蓝色或单一金色。

| Intent | 主色 | 辅色 | 使用范围 |
| --- | --- | --- | --- |
| `system` | `#42D9B5` | `#E8FFF8` | 发牌、聊天、托管、匹配 |
| `skill` | `#55DFFF` | `#B6FAFF` | 顺子、同花顺、连牌 |
| `honor` | `#FFD052` | `#FFF0B0` | 胜利、升级、贡还、玩家出完 |
| `power` | `#FF5B24` | `#FFD56A` | 普通炸弹、六张炸弹 |
| `royal` | `#F5C84B` | `#C7374F` | 天王炸、逢人配 |
| `neutral` | `#B2C2C4` | `#EEF3F1` | 失败、取消状态 |
| `ink` | `#02090D` | - | 暗场、标题描边 |

颜色 token 保存为不可变 RGB 元组。渲染时必须创建新的 `Color`，避免 Cocos 可变颜色对象污染全局样式。

## 动效语法

每个效果按同一条时间线组织：

1. `anticipation`：准备或飞行，不遮挡操作。
2. `impact`：命中时同时触发音效、触觉、闪光和震动。
3. `settle`：主体、冲击波和标题完成识别。
4. `release`：烟雾、碎片和文字退出并归还对象池。

基准时间为闪光 60-80ms、普通进入 160ms、冲击扩散 240ms、退出 180ms。飞行使用二次 Bezier；加速使用 `quadIn`，撞击扩散使用 `expoOut`，余波使用 `sineOut`，退出使用 `quadIn`。`backOut` 只允许英雄级标题或徽章使用，视觉过冲不超过 1.04。

## 层级与排版

固定层级如下，renderer 不再自由分配任意 z 值：

| Layer | 值 | 内容 |
| --- | ---: | --- |
| `DIMMER` | 0 | 暗场 |
| `BACK_FX` | 10 | 环境辉光、烟 |
| `TRAIL` | 20 | 飞行拖尾 |
| `SUBJECT` | 30 | 炸弹、纸牌、皇冠 |
| `CORE` | 40 | 热核心、命中点 |
| `PARTICLE` | 50 | 火星、碎片、彩纸 |
| `COPY` | 60 | 标题、状态文字 |

统一字阶为 `micro 18/24`、`caption 24/30`、`badge 34/42`、`title 46/54`、`hero 54/64`。标题使用 3px 墨色描边，徽章使用 2px；状态提示不使用英雄级字号。

## 性能预算

| 等级 | Full 粒子 | Reduced 粒子 | Full 烟/环 | 建议总时长 |
| --- | ---: | ---: | --- | ---: |
| L0 反馈 | 2 | 1 | 0 / 1 | 160-240ms |
| L1 普通牌型 | 8 | 3 | 0 / 1 | 300-420ms |
| L2 炸弹 | 24 | 8 | 3 / 2 | 620-760ms |
| L3 大牌型 | 40 | 12 | 5 / 3 | 900-1050ms |

Full 同时最多 96 个瞬态节点，Reduced 最多 32 个；同一时间最多一个主特效。Reduced 禁用暗场、烟雾、持续拖尾和震屏。Off 保留语义音频，不产生视觉和触觉。

## 效果映射

| 家族 | Intent | 统一表现 |
| --- | --- | --- |
| 普通出牌 | `system` / `skill` | 真实牌面飞行、轻落点圈；仅有识别价值的组合显示短标题 |
| 普通炸弹 | `power` | 实体炸弹 Bezier 投掷，到达后使用同包贴图完成闪光、核心、冲击、火星、碎片和烟 |
| 六张炸弹 | `power` | 真实牌面六牌阵配合金焰贴图；裂地层在专属素材交付前关闭 |
| 同花顺 | `skill` | 冰蓝流线、轻暗场、技巧标题和定向火花 |
| 天王炸 | `royal` | 金色主体、红色点缀、四王牌阵和最高级冲击 |
| 逢人配 | `royal` | 红金替代标记，时长和预算保持 L1 |
| 发牌/聊天/托管/匹配 | `system` | 玉青轻反馈，不与主牌型争抢亮度 |
| 进贡/还贡/升级/胜利 | `honor` | 暖金轨迹与标题；胜利可以使用受预算约束的彩纸 |
| 失败/取消 | `neutral` | 灰银短反馈，不使用暗场和强震动 |

## 素材和接入规范

运行时素材必须登记在 `EffectAssetCatalog`，包含来源、SPDX 许可证、SHA-256、资源路径和允许质量档位。生产特效只允许通过 `Sprite` / `SpriteFrame`、粒子贴图、Material / Effect、真实牌面和动画曲线呈现；严禁用 `Graphics` 的圆、线、矩形、多边形或路径绘制替代美术素材。

素材加载失败或尚未制作时，renderer 必须关闭对应视觉层，同时保留生命周期、音效时点和清理逻辑。不得生成几何占位，不得让透明节点假装成投掷物，也不得混用 `Graphics` 与 `Sprite` 作为同一节点的 2D Renderer。

普通炸弹投掷物固定使用 `bomb.body`，拖尾使用 `bomb.trail`，命中阶段使用 `bomb.hot-core`、`bomb.spark-streak` 和 `bomb.debris`。五张贴图全部加载完成后才开始飞行，以确保首次播放也能看到从行动座位沿二次 Bezier 飞向出牌区的实体投掷物。

炸弹 v1 素材由 `scripts/generate-bomb-vfx-assets.py` 确定性生成，包括炸弹主体、拖尾、热核心、火星、碎片和周期噪声。`noise-tile` 为后续热扰动 Effect 保留；微信小游戏首版可以不启用该 Shader，先保证兼容性和包体。

## 美术交付缺口

以下视觉层必须由透明 PNG / WebP、序列帧图集、Spine 或经过移动端验证的 Effect 补齐，交付前保持关闭：

- 54 x 76 @2x 的发牌牌背图集，以及 74 x 106 的进贡牌 prefab / 正面资源。
- 胜利专用彩带、彩纸图集，玩家出完奖牌和匹配成功徽章。
- 天王炸专属皇冠、逢人配专属徽记、六张炸弹裂地贴图。
- 左右方向各三帧的聊天提示图集。
- 普通炸弹终版序列帧火焰、烟雾、热扰动图；当前 `bomb-v1` 是可运行首版资源，换皮只替换 catalog 指向，不改控制代码。

## 验收门禁

- Cocos Creator TypeScript 检查和 Web 构建通过。
- EffectLab 覆盖四个座位起点、L0-L3、Full/Reduced/Off。
- 音效、震动和闪光绑定同一 impact 时刻，不能提前双播。
- 屏幕比例变化时 root 使用真实 viewport，标题不溢出或遮挡操作。
- 所有瞬态节点在完成、跳过、重连和销毁时释放。
- 新增 live renderer 不允许绕过统一色彩、字阶、层级和预算 API。
- CI 扫描全部生产 VFX renderer，出现 `Graphics` 或几何路径 API 立即失败。
