# 当前开发与验收基线

更新日期：2026-09-13。本文描述当前源码的能力与边界，不代表已上传微信、已部署服务器或通过真机验收。日期化交付、调参和发布记录保留历史语境，不用来恢复已退役功能。

## 玩家能力

| 入口 | 当前实现与限制 |
| --- | --- |
| 经典 | 经典随机级牌单局、不洗牌多炸随机级牌单局、连打过 A。不洗牌是组合更集中的单局发牌，不是沿用上一局收牌顺序。 |
| 好友房 | 经典、转蛋、八人双桌复式；创建后进桌，六位房号弹窗加入，微信卡片邀请。不展示长口令复制/粘贴或虚构好友列表。 |
| 房间座位 | 四/八席、空位添加机器人、准备/取消、允许时换座或退到观战位；以服务端 capabilities、成员资格和房间状态为准。 |
| 观战 | 好友房内允许的实时/延迟观看；服务端按规则授权手牌。旧独立 HTTP 观战页面不是玩家入口。跨桌版本空间独立，不能拿上一桌 revision 拒绝下一桌状态。 |
| 转蛋 | 抽牌换队或顺时针轮换；3 分制为胜负 ±3/±2/±1，6 分制为 6:0、5:1、4:2；按本局队伍结算和决策。 |
| 复式 | 两桌相同发牌；固定打 2 或共同随机级牌、不进贡、不升级。胜队得 3/2/1、败队 0，两桌红蓝队分数累加；未同时结束不推进下一局。隐藏比分设置同样约束局中摘要。 |
| 16 人赛事 | 3 轮、每轮 4 桌换桌，随机级牌只打一副，个人名次 3/2/1/0 分；最终前 8 标记晋级，不自动生成淘汰赛。报名、取消报名、检录、分桌和结果均为真实平台流程。 |
| 个人资料/我的对局 | 默认资料、昵称编辑/头像选择、微信支持的主动授权与好友排行；查看授权公开事件回放。微信真实身份、头像上传、好友数据仍需真机与平台配置验证。 |
| 商城 | 商品预览；不开放下单、商户运营或虚构奖励。 |

## 牌桌规则和策略

- 提示、托管、机器人使用最高档团队决策，不恢复低档策略。AI 缓存、RNG、公开信息推断与决策记录按实例隔离；不得读取不获授权的暗牌。
- 机器人常规等待由 `server/bot-turn-pacing.js` 将实际计算耗时放大 50 倍后限制在 0.5–3 秒，10% 概率再乘 3；特殊阶段和真实截止时间优先。普通匹配补位默认 3 秒（`platform/match-bot-fill.js`），不是旧文档的 7 秒。
- 一键理牌采用简单规则，先识别大组合；不自动搜索普通顺子、不做分帧穷举或要求平均六手。普通顺子交给玩家选牌后锁定。
- 锁定只接受当前规则合法组合，任意成员整体选中/取消；一键复原保留有效手动锁。没有分组 undo/redo。
- 同花顺按 5.5 张炸弹强度比较；A2345 展示顺序根据代表点数判断，不把炸弹强度当顺子端点。
- 记牌器同花顺指示是“公开未知牌仍可能组成”的上界，不是确定暗牌或概率；普通级牌不能直接充当顺子点数，红心配在通配池只计算一次。无可能时四花色变灰而非移除组件。
- 结算展示和统计记账分离。统计按稳定 match/table/participant/round 身份去重并持久化有界账本；无可信对局身份的旧事件只展示、不累计。房号重复不是新旧对局身份判断。

## 开发所有权

共享规则源为 `shared-core/src`；`scripts/sync-core.mjs` 生成客户端 39 份副本（以 `verify:core-sync` 实际结果为准），不能双算独立源码或直接修改生成目录。

- `createAIEngine` 装配唯一最高策略；`team/policy`、`handRoute`、`handStrength`、`belief`、`holdingShapes`、`tableOutlook` 分离决策与推断，`team/journal`、`checkpoint`、`ruleMemo` 管理实例记录和缓存。
- `GameManager`/`NetworkMatchSnapshotController` 投影权威快照，`GameSession` 持有本地统计与持久化；`TableMatchCoordinator` 仅协调展示和短期交互代际。
- `LobbyResumeSession` 保存恢复凭证并做校验，重连成功轮换，退出清理；写入失败不阻塞当前牌局。不能声称仅同进程可恢复，也不能据此保证所有手机冷启动成功。
- 房间关闭协调器、平台成员事务和赛事屏障分别拥有自己的持久化/重试边界；仍是单实例架构，不等于分布式原子事务或自动故障转移。
- 新职责进入独立模块，遵守既有行数预算与依赖方向。文件清单由 `audit-code-health.mjs` 生成；静态可达和测试提及都不是分支覆盖率。

## 音画与退役边界

只保留女声报牌、三种不要、倒计时、发牌/胜负和允许的炸弹声；钢板使用独立 TTS。非炸弹以飞牌和一次报牌为准。骨骼动画暂不接入，不能用整图浮动冒充。

以下入口/能力保持退役：游戏内实验室和控制台注入、快捷语/气泡/网络广播、男声与切换设置、级牌专属声、重复同花顺语音、出牌电子音及被拒绝的光环。`tests/quick-chat-regression.cjs` 是防回流测试，`fixed-match-fixtures-regression.cjs` 是包外夹具验证，`merchant-console-regression.cjs` 是迁移边界验证；不得按名字误删。

当前第三方资源清单见 [THIRD_PARTY](../THIRD_PARTY.md)。历史源码、素材归档和许可证留在包外；本地哈希/开源工具许可不等于每个美术、头像、TTS 或音效的独立商业授权证明。

## 验证与发布

执行客户端 `test:ci`、`typecheck:runtime`、`typecheck:migration`，服务端 `check:server` 与 `test:server`；新增失败回归必须登记到默认测试链。可控端口、时钟和内存 DTO 的测试不冒充微信原生 API、GPU、多人手机或音频听感验收。

微信/Web 必须用当前源码重新构建，再执行目标平台 finalizer 和完整 build 校验；仅包体结构通过不证明代码已更新。客户端构建与服务器部署分开交付，不沿用历史包体数字和线上健康描述。
