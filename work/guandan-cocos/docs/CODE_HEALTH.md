## 不删除的三类非主运行入口

- `shared-core/src/lib/ai.ts`：旧端/worker 的兼容导出路径；原共享源保留，Cocos 同步策略排除这一孤立门面，不应破坏旧端调用约定。
- `server/index.js`：主动报错的退役入口，避免误启旧服务；它不是还在运行的旧 WebSocket 实现。
- `server/hk-bare-ip-profile.js`：独立联调预检 CLI 的依赖，不进入小游戏运行包；保留其禁止生产裸 IP 配置的防护。

上述文件有明确的保留原因清单；新增“仅被测试引用”的模块不会自动获得豁免。类型文件、Cocos UUID 序列化组件也不能按普通脚本的 import 搜索结果直接删除。

## 开发入口与状态所有权

| 要改的能力 | 应优先进入 | 不应做的事 |
| --- | --- | --- |
| 大厅/资料/好友房界面 | `scenes/front-pages` 的对应 Presenter 与 Domain | 向 `GameScene` 添加页面业务 |
| 手牌排布/选牌/理牌 | `game/HandWorkspace`、`HandGrouping`、`ui/HandController` | 用视图节点位置修改权威手牌 |
| 牌桌信息/记牌器 | `TableHudPresenter`、`TableHudDynamicRenderer`、独立纯策略 | 在渲染器读取其他人的隐藏牌或处理网络登录 |
| 牌型/级数/贡还/AI | `shared-core/src`，测试后同步 | 手改 `assets/scripts/core/generated` 或 `dist` |
| 联机动作/重连 | `network`、`TableMatchCoordinator`；服务器 command handler | 客户端自行宣布动作已成功，或另建第二套真实状态 |
| 匹配/好友房/账号 | `server/platform` 的领域服务及对应 gateway | 把事务逻辑放进 HTTP/WS 收包函数 |
| 音效/动效 | `audio`、`effects` 的语义调度与 renderer | 播放器推进回合，或重新启用已退役效果 |

`GameManager` 管理牌局应用状态，`LobbyController` 管理权威网络房间投影，`GameSession` 管理页面/席位身份、偏好与统计；组件装配和生命周期桥接归组合根。详细约束仍以 [ARCHITECTURE.md](ARCHITECTURE.md) 为准。

## 新增门禁与复现命令

```sh
# Cocos 根目录
npm run verify:architecture    # 分层、循环、预算、缺失引用、孤立 .meta
npm run verify:retirement      # 退役入口、包外源码边界、旧音频及归档哈希
npm run verify:health          # 三端源码入口清单，孤立文件必须人工说明
npm run audit:health           # 输出逐文件 Markdown 清单（只读）
npm run typecheck:runtime      # 本机有 Creator 类型声明时完整检查
npm run typecheck:ci-core      # 不依赖 Creator 的纯模块检查
npm run typecheck:migration
npm test
```

客户端与共享规则已开启 `noUnusedLocals` / `noUnusedParameters`，`test:ci` 增加代码健康门禁。服务端检查补齐本地 import/require 目标存在性校验，保留语法、依赖环、测试登记与预算检查。运行工具不会读取 `.env` 或输出凭据，不会改写项目文件。
