# 大厅动效第一批 · 2026-09-07

## 已接入 Cocos

- 只装饰快速开始／继续牌局按钮，不改 approved 大厅布局、180px 账户底、70px 商城图片、商城文字及背景。
- 3 秒初始静置，每 10 秒一次 16 帧、15fps 的角落微光。没有横向扫光、全屏闪白、循环漂浮或新增电子音。
- 22px 角落精灵位于按钮内部，55/255 峰值透明度的内沿高光，不遮盖文字。
- 按住按钮、恢复牌局、打开路由弹窗、切后台时停止。恢复后先静置，不补播。精简／关闭特效和浏览器减少动态效果均停止装饰。
- 不绑定触摸事件、不修改按钮 transform。切页取消异步加载并销毁动态 SpriteFrame，纹理由原 bundle 管理。
- 资源失败退回原静态按钮，不阻塞大厅和匹配入口。

代码：`LobbyMotionPolicy.ts`（节奏）、`LobbyAmbientMotion.ts`（Cocos 装饰组件），由 `LobbyPageDomain.renderQuickStart` 接入。时钟归页面领域对象所有，账号刷新和安全区重排不会重新开始一轮循环。
