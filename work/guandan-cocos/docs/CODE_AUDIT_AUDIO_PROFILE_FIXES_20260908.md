# 音频与个人资料异步边界修复

日期：2026-09-08。对应本轮抽查的四个问题；不修改布局、素材、女声选择、牌局规则或服务端。

## 修复与职责

| 问题 | 修复 | 状态所有者 |
| --- | --- | --- |
| 关闭重开资料弹窗后，旧保存响应覆盖较新的昵称 | 保存按提交顺序执行，只有最新请求发布结果；单次保存即使关闭弹窗仍可完成 | `services/ProfileSaveCoordinator.ts` |
| 网络超时被永久记为资源不存在，之后一直无声 | 明确缺失才永久缓存；未知错误、网络和超时允许有限重试 | `audio/OptionalAudioAssetCache.ts` |
| 冷加载返回 B → A，语音也错序播成 B → A | 出牌与“不要”共用最新动作门禁，旧请求失效；没有配音的新动作也会使旧报牌失效 | `audio/ActionVoiceGate.ts` |
| 只销毁音频组件、保留节点时，迟到 BGM 回调重启音乐 | 先置销毁状态，再取消加载和重试定时器、清理缓存；迟到和重复回调不能重新写缓存或播放 | 缓存拥有加载生命周期；`CocosAudioController` 拥有音源生命周期 |

弹窗代次只控制当前窗口的关闭、提示与忙碌状态，不能代替保存事务顺序。排队执行前校验用户身份，防止等待期间切换账号后提交到另一账号。最新保存失败时读取服务端资料进行核对，失败草稿不发布；恢复读取也失败则保留当前显示，并允许重试。

## 固定策略与边界

- 每个音频资源最多初次加载加 2 次自动重试，间隔 500 ms、1500 ms；耗尽后 5 秒内不发新请求，之后下一次请求可重新加载。BGM 的有限重试不依赖用户再次点击。耗尽后的重试需要后续设置/场景请求，不是永久后台轮询。
- `ASSET_LOAD_TIMEOUT`、取消和未知失败不是永久缺失；明确的 404、ENOENT 或 bundle 不包含资源才进入缺失缓存。可选缺失仍能尝试配置中的下一个候选。
- 报牌请求有效期 1800 ms。迟到的加载结果可以缓存供下一次使用，但不会补播旧回合；不会为了等声音暂停规则、网络或按钮。
- 最新动作门禁只作用于动作语音与“不要”；独立 BGM 和其他声音不被新动作统一取消。它不是混音器，不声称中断已经开始播放的每一段 `playOneShot`。
- 退役级牌专属音、电子出牌音和男声资源没有恢复。
- 加载器支持同步回调，取消也可能同步回调；清理先使请求失效，再调用取消函数。异步加载不能仅凭节点存活判断组件仍存活。
