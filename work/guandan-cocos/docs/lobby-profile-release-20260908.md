## 微信 API 边界

本项目是 Cocos 微信小游戏，使用 `wx.createUserInfoButton`，不是普通小程序 WXML 的 `chooseAvatar` 组件。微信官方说明小游戏 `wx.authorize({scope:'scope.userInfo'})` 不弹授权窗，需使用用户信息按钮：

- https://github.com/wechat-miniprogram/minigame-tuanjie-transform-sdk/blob/main/Runtime/WX.cs
- https://github.com/wechat-miniprogram/minigame-tuanjie-transform-sdk/blob/main/Runtime/WXBase.cs

用户点击资料页授权入口后请求隐私授权并创建微信原生按钮，再点击原生按钮取得资料；界面提示这一确认步骤。原生按钮映射到现有 Cocos 按钮矩形。关闭、切后台、重排会销毁原生按钮；迟到回调被忽略。补充重复隐私回调、重复资料回调及桥接同步异常的保护和测试。

仍通过现有平台头像代理加载 HTTPS 微信头像，不新增请求域名。没有自动弹授权，没有把登录当作昵称头像授权，也没有替用户授予真实权限。

## 微光核查结论

- 仅“快速开始／继续牌局”的按钮角落序列帧微光及内沿高光接入；其他入口未新增微光，骨骼动画仍暂停。
- 实际 Web 发布构建采样 11 秒，读到全部帧 `0…15` 及静置帧 `-1`；纹理 384×96，内沿透明度峰值 55/255，按钮缩放恒为 1。
- 初次静置 3 秒、每 10 秒一次；精简／关闭特效、减少动态效果、按住按钮及后台等状态停止。
- 本次微信包同时包含 `LobbyAmbientMotion` 与 `effects/lobby-v1/button-glint/texture`。打包成功不等于已经上传或发布；本轮未上传微信、未部署服务器。
