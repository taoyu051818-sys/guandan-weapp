# 好友房逐席添加机器人：2026-09-09

## 用户范围与实现

- 四人经典／转蛋和八人复式房：每个空位下方显示绿色「添加机器人」，「坐下」保留为独立按钮，原加号仍可作为房主添加的快捷入口。
- 保留统一小圆角方框。按 UI/UX 检查分离触控区域；四人并排按钮间隔 8 个设计单位，八人添加按钮在座位面板内独立成行。
- 房主可操作；非房主和开局确认中禁用。公开匹配房不提供手动机器人管理。
- 不覆盖在线玩家、签名房中离线保留的席位或已经存在的机器人。开局后不得增删。
- 四人签名好友房新增独立机器人身份模块 `server/friend-room-bots.js`，机器人标识随房间持久化。签名开局名单由平台验证，允许机器人入席而不创建虚假账户或钱包。
- 经典固定局数、转蛋完整对局和结算接通；传统升级的好友房机器人参与计算，但不生成机器人账户、钱包、排行或结算流水。已有真人结算规则不改变。
