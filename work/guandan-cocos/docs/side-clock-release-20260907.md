# 左右闹钟与匹配节奏验收（2026-09-07）

## 本轮变化

- 左右闹钟不再使用 `x=±500, y=105` 的独立固定位置。
- `PlayedCardLayout.turnTimerPosition` 复用对应座位单张出牌位置，落在出牌区靠头像的一端。下一手牌张数未知，因此不随上一手组合牌宽度漂移。
- 我方操作行、对家倒计时、时长、动画素材和现有层级不变：桌面牌 < 手牌 < 飞牌/特效 < 操作按钮 < 弹窗。
- UI/UX 检查用于安全区和空间一致性，没有更换美术资源，也没有强制排除正常重叠。

## 机器人与匹配：核对既有实现

- 来源仍为 MIT 的 [XadillaX/chinese-random-name](https://github.com/XadillaX/chinese-random-name)，采用经过筛选的姓氏子集和组合思路，搭配本地短昵称词库；来源提交与许可证见服务端 `third-party/chinese-random-name.md`。
- 昵称为虚构显示名，同桌去重，恢复与重启后稳定；不抓取真实个人资料，不宣称“真人认证”。
- 普通匹配在最早玩家等待满 3 秒后补位，通过下一次轮询返回结果。赛事不补机器人。
- 匹配页不显示机器人补位或连接确认过程；保留匹配动画、取消操作和真实错误反馈。好友房主动添加机器人仍保留明确配置说明。
- 普通动作约 488–975ms；炸弹或拆对子/三张/炸弹按回合开始计时随机 1.2–3 秒，且不得越过服务端 deadline。重启或重试不重新选择牌和延迟。
- 已逐个比对线上 `player-nicknames.js`、`bot-turn-pacing.js`、`platform/match-bot-fill.js`、`weapp-turn-clock.js` 与本地哈希，四项一致，本轮未重写已生效的服务端节奏。

## 验证

- 客户端全量回归、203 模块/42 项架构预算、核心同步和 CI 类型检查通过。
- 新增不同宽度和不对称安全区测试：874×402、1280×720、1565×720、1792×720；左右闹钟与各自出牌锚点相等，安全区修正不使其偏离。既有落桌前 0.8 缩放、按钮层级、触摸选牌回归通过。
