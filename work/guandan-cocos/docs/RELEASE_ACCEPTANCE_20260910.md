## 判定与反馈格式

- 每项填写“通过 / 失败 / 未覆盖”，附图片或录屏编号；不能用“差不多”代替结果。
- 不能入桌、丢牌/重复操作、分数错误、手牌泄露、创建/邀请失败等任一问题，阻止发布。
- 转蛋、复式和赛事若未覆盖，相应模式不能签为已验收；是否延后开放需要单独决定。
- 新发现问题记录：`ID｜机型/微信版本｜房间号｜发生时间（时区）｜操作步骤｜实际结果｜期望结果｜证据编号`。日志和截图注意遮挡个人信息。
- 修复后先重测失败项，再重测 A01、A04–A08、A12、A19、A20 的主流程，防止回归。
