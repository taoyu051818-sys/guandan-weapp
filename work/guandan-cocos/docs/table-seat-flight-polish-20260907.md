# 牌桌姓名、出牌位置与落桌前缩小（2026-09-07）

## 本轮范围

- 姓名字号从 28 调到 22（Cocos 设计单位）；左右两家改为头像在上、姓名在下、剩余牌数/名次在最下。
- 左右出牌朝头像内侧的牌桌展开，并跟随安全区宽度定位。
- 我方与对家的出牌锚点共用横坐标，分别在 y=78、185，上下相邻。坐标是牌桌本地坐标，不是截图像素。
- 飞牌从 scale=1 逐渐缩到 0.8；在飞行进度到 80% 时完成，剩余路程保持 0.8。**不在落桌后播放缩小。**
- 静态桌面牌从创建时就是 0.8，飞牌终点间距也乘 0.8，避免临时牌与正式牌交接时跳变。
- 重连、跳过、资源失败直接显示最终尺寸，不补播缩小；“不要”仍是文字，不套牌框。
- 不修改手牌选中动画、不重新强制分组避开中央、不修改大厅素材或布局，不恢复已卸载的特效。

- `assets/scripts/ui/TableHudSeatViewGroup.ts`：姓名字号、左右信息纵向排列。
